# Computing Adventure
Gentle computer literacy for children: keyboarding, mouse skills, a pretend desktop, digital safety and online kindness. Vanilla-JS PWA, no build step. Served at computing.jacobsiler.com.

- Nothing children type is stored or sent. Stars/badges sync only if a family code is joined (Firestore doc `families/{CODE}_ca`; rules must allow that path).
- Deploy: double-click `push.cmd` or use the tray watcher (see README-deploy.md).
- Help line numbers in `ca-oops.js` should be re-verified periodically.
